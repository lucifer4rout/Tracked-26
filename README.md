# Tracked.26

### Your JEE 2027 journey, tracked in one place.

**Tracked.26** is a modern desktop application designed to help JEE aspirants organize and track their preparation.

Track your progress across **Physics, Chemistry, and Maths**, monitor chapter completion, log daily study activity with a visual heatmap, and stay focused with monthly targets and a live countdown to your exam.

> ⚠️ **Windows Download Warning:** Windows may occasionally show a security warning when downloading Tracked.26 because the application is new and has a low download/reputation history. **The file is safe and has been checked with multiple antivirus/security scanners.**
>
> 📖 **Seeing a warning?** Follow the [Windows security warning guide](https://github.com/lucifer4rout/Tracked-26/issues/3) for instructions on how to continue the download.

---

## ✨ Features

### 📊 Progress Dashboard

Get a quick overview of your JEE preparation with:

* Live countdown to JEE
* Physics, Chemistry and Maths progress
* Overall chapter completion tracking
* Custom exam date selection

### 📚 Subject & Chapter Tracking

Manage your JEE syllabus chapter by chapter.

For every chapter, track:

* Lectures
* Notes
* Short Notes
* Revision
* Tests
* Chapter status

### 🔥 Study Heatmap

Build consistency by logging your daily study activity.

The heatmap gives you a visual overview of your preparation throughout the year.

### 🎯 Monthly Targets

Set clear goals for each month and track what needs to be completed.

### ➕ Custom Subjects & Chapters

Not limited to the default structure — add your own subjects and chapters to make the tracker fit your preparation.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/tracked-26.git
cd tracked-26
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

---

## 📦 Build for Windows

To create a distributable version:

```bash
npm run dist
```

The packaged application will be generated inside the `dist` folder.
